# My Market App — Витрина интернет-магазина

Веб-приложение «Витрина интернет-магазина» на Spring Boot (блокирующий стек):
просмотр товаров, поиск, сортировка, пагинация, корзина, оформление и просмотр заказов.

## Стек технологий

| Слой | Технология |
|---|---|
| Язык | Java 21 |
| Фреймворк | Spring Boot 4.1.1 |
| Web | Spring Web MVC + Thymeleaf |
| Persistence | Spring Data JPA + Hibernate ORM |
| БД (prod) | PostgreSQL 16 |
| БД (dev/test) | H2 (in-memory) |
| Сборка | Maven |
| Тесты | JUnit 5, Spring Boot Test, MockMvc, Testcontainers |
| Контейнеризация | Docker, Docker Compose |

## Функциональность

- **Витрина товаров** (`/`, `/items`) — список карточек с изображением, названием, описанием и ценой; поиск по названию/описанию, сортировка (без сортировки / по алфавиту / по цене), пагинация (2, 5, 10, 20, 50, 100 на страницу), кнопки изменения количества прямо из списка.
- **Карточка товара** (`/items/{id}`) — детальный просмотр, добавление в корзину, изменение количества.
- **Корзина** (`/cart/items`) — список добавленных товаров, количество, цена за единицу и общая сумма, удаление позиций, оформление заказа.
- **Список заказов** (`/orders`) — все оформленные заказы с составом и суммой.
- **Страница заказа** (`/orders/{id}`) — состав заказа: название, цена, количество, сумма.
- **Оформление заказа** (`POST /buy`) — переносит корзину в заказ и очищает её.
