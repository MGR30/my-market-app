# My Market App — Реактивная витрина интернет-магазина

Веб-приложение «Витрина интернет-магазина», переписанное с блокирующего стека (Spring MVC + JPA) на **реактивный стек** (Spring WebFlux + Spring Data R2DBC).

## Стек технологий

| Слой | Технология |
|---|---|
| Язык | Java 21 |
| Фреймворк | Spring Boot 4.1.1 (или 3.5.x) |
| Web (Реактивный) | Spring WebFlux + Reactor Netty |
| Шаблонизатор | Thymeleaf (реактивный) |
| Persistence (Реактивный) | Spring Data R2DBC |
| БД (dev/test) | H2 (in-memory, R2DBC) |
| БД (prod) | PostgreSQL 16 (R2DBC) |
| Сборка | Maven |
| Тесты | JUnit 5, Spring Boot Test, WebTestClient, Reactor Test, Testcontainers |
| Контейнеризация | Docker, Docker Compose |

## Реактивные особенности реализации
- **Non-blocking I/O:** Все слои приложения (контроллеры, сервисы, репозитории) используют `Mono` и `Flux`. Блокирующих вызовов (`.block()`) в основном коде нет.
- **Spring Data R2DBC:** Репозитории наследуются от `ReactiveCrudRepository`. Вместо JPA-сущностей со связями используются плоские таблицы (например, `orders` и `order_items` связываются через `orderId` вручную).
- **Чтение форм:** Для надежного парсинга `application/x-www-form-urlencoded` в POST-запросах используется `ServerWebExchange.getFormData()`, что исключает проблемы с `@RequestParam` в WebFlux.
- **Обработка ошибок:** `GlobalExceptionHandler` возвращает `Mono<Rendering>` и корректно обрабатывает `NoResourceFoundException` (favicon) и `MissingRequestValueException`.

## Функциональность

- **Витрина товаров** (`/`, `/items`) — карточки товаров с пагинацией (от 2 до 100 на страницу), поиском по названию/описанию и сортировкой (по алфавиту / по цене). Добавление в корзину прямо со страницы витрины.
- **Карточка товара** (`/items/{id}`) — детальный просмотр и изменение количества в корзине.
- **Корзина** (`/cart/items`) — список выбранных товаров, их количество, цена и общая сумма. Удаление позиций.
- **Список заказов** (`/orders`) — история оформленных заказов с составом и итоговой суммой.
- **Страница заказа** (`/orders/{id}`) — детали конкретного заказа.
- **Оформление заказа** (`POST /buy`) — перенос товаров из корзины в заказ.
- **Загрузка изображений** (`/images/{filename}`) — отдача статических картинок.
